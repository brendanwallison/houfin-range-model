## Verification: epoch selection, held-out set, resume (2026-10-30, coordinator question; before any Stage E score)
- **Weights exported = FINAL epoch 500 (established).** The log line "[desk] epoch selection on val_kernel ..." is a
  header printed unconditionally. With `desk.trend.holdout_frac` = 0 the internal split draws no blocks ("split: 6x6-cell
  blocks, buffer 1 cells -> 0 val, 0 buffer cells"; "0 cells held out for eval, 0 buffered"; "val kernel pool (pool):
  EMPTY"). The selection criterion is then NaN every epoch, `best` is never set, and the trainer keeps the final weights
  (log: "keeping the FINAL weights from epoch 500: no validation cells ..."). run_summary: best_epoch 500,
  restored_best false, n_val_cells 0, epochs_run 500, resumed_from_epoch null -- identical in form to the 27 km
  desk_interp_s1 (best_epoch 500, restored_best false, n_val_cells 0, epochs_run 500). Production: the same
  (2,555 cells, 87,524 cell-years, best_epoch 500, restored_best false).
- **The internal held-out set is empty, so it cannot touch evaluation places.** The external evaluation (54 km holdout
  and buffer cells, the 219-cell withheld panel, the reserved modern/historical halves) is excluded upstream from every
  training source (Stage B/C leak checks); DESK's `holdout_cells.npy` / `buffer_cells.npy` in the model dir are its own
  (empty) internal split, not the twin masks. `patience` = 500 = epochs, so early stopping cannot fire.
- **Resume path (established from code; NOT exercised: the twin ran on a gpu-a100-small worker and finished in one go,
  13:42, 500/500 epochs, resumed_from_epoch null).** Checkpoints every 10 epochs are written atomically (tmp + replace)
  and fingerprinted on the configuration; on rerun z_coord_run skips nothing until TRAINING_DONE, and the trainer
  restores model, output-EMA (incl. the learned half-life), aux / presence / metric heads, optimizer, LR scheduler,
  best/bad/crit history and every RNG, then continues from epoch+1. The trajectory file keeps only rows below the resume
  epoch (re-run epochs are rewritten once). The EMA warmup start (1902) is a config constant, and the EMA cube is
  recomputed from the exported raw cube. Twin and production trajectories: 500 rows, epochs 1-500, unique, sorted.
- Trained half-lives: twin 10.91 yr, production 10.90 yr (27 km desk_interp_s1: 11.03). Twin cube done 13:41,
