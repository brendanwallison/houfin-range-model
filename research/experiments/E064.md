# E064 An effort model for raw CBC counts: does it reproduce Audubon's trends, and does it hold before 1940?
# (pre-registered 2026-10-13 ~16:30, before any fit; a 40-step code smoke was run, no gate statistic seen)
hypotheses: [CBC (bridge / complement)]     parents: [E063, E061, plans/raw_surveys.md (C1, gates C-a, C-b)]
eval_version: pre-v1     cost: 2 x ~20 min cpu + ~5 min
why: the user (2026-10-13) approved the raw-survey plan. E063 found CBC's withheld-era change adds +0.07 beyond
extrapolating BBS's later trend (more for common species) -- a complement, carried by CBC's coverage of the years BBS
lacks. Using CBC where it matters (before 1966, and above all 1902-1939) needs our own effort model on the raw circle
data: Audubon's product starts in 1966, and party-hours -- the standard CBC effort measure -- are missing for nearly
every count before 1940 (0% 1901-1919, 6-7% in the 1920s-30s, 56% in the 1940s, >= 92% from the 1950s), while the number
of field counters is recorded for ~100% throughout.
data: the Audubon CBC full data request (E:/Datasets/cbc_raw, 2025-02-05), prepared by research/exp/cbc_prepare.py:
103,188 circle-years (study box, US + Canada), 4,740 circles, 174 state/province x BCR strata (BBS USGS/CWS polygons),
winters ending 1901-2025, 79 species = the cache's reference + dev species with an Audubon product of medium/high
suitability (32 reference). Zero-filled; count-week records are zeros.
model (research/exp/cbc_effort_model.py): per species, NB2 with a circle effect, a stratum x year effect (first-order
random walk over years, sd 0.3), effort as a species-specific power function (Link & Sauer 1999) of party-hours
("ph", circle-years with party-hours) or of field counters ("counters", all years), plus log1p feeder hours and
log1p nocturnal hours; ridge penalties stand in for random effects; Adam, 6,000 steps; 10% of circle-years held out.
Stratum index = exp(stratum-year effect) x mean over the stratum's circles of exp(circle effect): a typical circle at
mean effort (Audubon's definition). v1 has no weather terms (planned for v2 if the gates pass).
gates (research/exp/cbc_effort_gates.py; fixed now):
- C-a VALIDATION vs Audubon (1967-1986 -> 2005-2024 change, strata with >= 3 fitted circle-years in each window):
  PASS if species-level corr >= 0.8 AND pooled stratum-level corr (each species' mean removed) >= 0.6 [the plan said
  0.8 for both; the stratum-level bar is set at 0.6 here, before any fit, because Audubon's model smooths spatially
  (BYM / spatially varying coefficients) and ours does not, so stratum-level differences are expected from the model
  form alone -- flagged as a change from the plan]. Also reported: within-stratum trajectory corr 1967-2024.
- C-b (i) EFFORT PROXY: counters-only vs party-hours models, stratum change 1950-57 -> 1958-65 and 1967-86 -> 2005-24:
  PASS if pooled corr >= 0.8 in both periods.
- C-b (ii) EARLY PREDICTION: held-out Spearman (median over species) of the counters model before 1940 >= 0.75 x its
  value after 1966.
decision: C-a and both parts of C-b pass -> the counters model is a usable early-era CBC index: next, v2 (weather; a
comparison of alternative effort forms) and the E063-style complement test in the withheld era with OUR index, then
the DESK bridge test (plans C2). C-a fails -> fix the model before any early use (likely: spatial smoothing, effort
form). C-b fails -> counters are not an adequate effort proxy before 1940; report which part and stop early-era use.
considerations: M29 (Audubon's own choices: trends from 1966; effort-adjusted hierarchical models), M2/M13 (report CI-
free point gates with their n; a skeptic round before any finding), season (winter communities), sealed species never.

DIAGNOSIS (established): the species-level shortfall is a DATA bug, not the effort model. The raw file uses older
scientific names (Anas clypeata, Anas strepera, Grus canadensis, Anas penelope), so Northern Shoveler, Gadwall, Sandhill
Crane and Eurasian Wigeon were zero-filled throughout (our change exactly 0.00); and taxonomic splits/lumps put early
records under other names (Spotted Towhee: +2.99 vs Audubon +0.27; Red-naped Sapsucker +1.96 vs +0.06; Dark-eyed Junco
forms "(Slate-colored)", "(Oregon)" unresolved).
AMENDMENT (before any re-run result): cbc_prepare.py resolves names by scientific name -> common name -> binomial ->
base common name without the parenthetical; slash names stay unresolved, and species with >= 2% of records under a slash
naming them are dropped, plus known plain-name splits (Red-naped / Red-breasted Sapsucker, Spotted Towhee, Eastern
Screech-Owl, Tufted Titmouse). Dropped: bargol, easowl1, rebsap, rensap, spotow, tuftit -> 73 species (28 reference),
cbc_circles_v2.npz. Both fits and the gates are re-run on it with UNCHANGED thresholds. The first run is kept as recorded.

## E064b Is the pre-1940 predictive shortfall sparsity or the effort proxy? (pre-registered 2026-10-13 ~17:20, before running)
design: refit the COUNTERS model on post-1966 data THINNED to pre-1940 density -- per stratum and decade, randomly keep
as many circle-years as the stratum had per decade before 1940 (strata with none before 1940 get none) -- with the same
10% holdout, and score held-out Spearman on post-1966 rows for the SAME 33 species as the pre-1940 score.
reading: if the thinned post-1966 Spearman falls to within 0.03 of the pre-1940 value (0.423), sparsity explains the
shortfall and the counters model is judged adequate for early use at early density (C-b (ii) re-read as "density-matched
pass"); if it stays >= 0.10 above 0.423, early counts are genuinely harder to predict beyond density (proxy, observers,
taxonomy or coverage) -> no early-era use until that is understood. In between: report.
---- E064b RESULT (2026-10-13 ~18:00; jobs E064/cbc-fit-counters-thin-aa440b28d561, e064b-score-23e1fee0b86c) ----
Post-1966 fit rows thinned to pre-1940 density: 8,819 kept of 78,562. Same 33 species, held-out Spearman (median):
post-1966 full 0.764; post-1966 thinned 0.612; pre-1940 0.423. Gap thinned - pre-1940 = +0.189 (>= 0.10).
DECISION (pre-registered): early counts are harder to predict BEYOND density -> no early-era (pre-1940) use until the
cause is understood. Density explains ~0.15 of the 0.34 drop.
EXPLORATORY (not pre-registered; reported for steering): post-1966 held-out counts with EARLY-LIKE effort (<= 6 field
counters, the pre-1940 90th percentile; 1,025 rows) score 0.619 -- the same as density-thinning. Early counts: median 2
field counters (post-1966: 18); zero share 0.80 for these species (low-effort post-1966: 0.68; all post-1966: 0.53);
median non-zero count 6 (13; 28). Low effort and low density each explain ~0.15; ~0.19 remains.
WHY (unknown; candidates, cheapest test first):
(1) incomplete lists before standardized reporting -- zero-filling assumes every species seen was reported; test:
    species richness per count vs counters, early vs later at matched counters (fewer species at equal effort ->
    incomplete lists or smaller/shorter counts);
(2) unstandardized count protocol in the early decades (count area, duration) -- check CBC protocol history;
(3) observer identification skill; (4) where early circles were (towns, parks).
