# E033 Can a readout calibrated on trained years stop DESK's backcast change from doing harm -- and does the shrink
# learned in the BBS era carry over to the past?
hypotheses: [B1, B7, T10, S1]     parents: [E030, E012, E025]     eval_version: pre-v1     cost: rung 0, minutes
pre-registered: 2026-10-10 ~11:34 (the user chose "all four" at Gate 1; this is "readout scaling"), before running.

question: the readout turns DESK's withheld-decade change into species change far too large for its accuracy
(E030: k 0.19, skill -0.086). The best any rescaling could reach is corr^2 (~0.005 centred, ~0.02 uncentred for the
1996-start model), so the gain is capped near zero; the live questions are (1) whether a readout whose trust in
change is LEARNED on the trained years (the only years a backcast can learn from) avoids that harm, and (2) whether
the trust learned in the BBS era matches what the past needs (E019: calibration falls with reach).
considerations: M1 (report corr, k, skill separately; the cap is corr^2); M4 (centred and uncentred); M5/G3 (the score
asks for a species' whole change); G4 (shrink only as far as accuracy justifies -- this measures how far that is);
G5 (scaling cannot fix direction: corr must not change for R1); M14 (prevalence tiers); G6/M9 (selected AND epoch-490
states); G1 (the honest target: k ~ 1 in the past, not minimal movement).
design: research/exp/readout_scaling.py. R0 level readout (current); R1 = R0 x k learned on training cells' trained-
era change ([T0, T0+9] -> 2016-2025), pooled and per prevalence tier; R2 = split-block BLR on training cells' 5-year
windows in the trained years (place block = the cell's mean z, change block = the window's deviation, each with its
own learned amplitude; change read through the change block only -- a form the downstream contract allows). Scored on
held-out cells, withheld early epoch vs 2005-25. Caches: tempho1995 s1 and tempho1985 s1, selected and epoch 490.
predictions: (1) the trained-era k is well above the withheld-decade k (calibration decays with reach), so R1 still
over-moves into the past (skill < 0 but closer to 0 than R0); (2) R2's learned change-block amplitude is far below the
place block's (the BLR distrusts within-place change), so R2 moves much less than R0 -- skill near 0, corr possibly
different from R0 (it reads change through different coefficients). (3) If R1 or R2 reach skill >= 0 in withheld
decades, a calibrated readout is enough to stop the harm; if not, the past needs MORE shrinkage than the BBS era
teaches -- i.e. a reach-dependent shrink or uncertainty, which only the age model's prior can encode (G1, G4).

CAUTION before reading R2 as habitat (G3, M5, M11): R2's change coefficients are learned from training cells'

the species-dynamics signal G3 says habitat should NOT carry, and the "kind of place x linear year" structure E027c
found. Placebo test pre-registered as E033b before interpreting.

## E033b Placebo for the split readout (pre-registered 2026-10-10 ~11:40, before running)
design: the same split-block BLR on the same windows, with the change block replaced or extended:
  R2p   place block (cell-mean DESK z) + PLACEBO change block: position x time (24 smooth 300 km position features
        times the window's year minus the cell's mean year) -- a species-specific regional trend, no DESK change;
  R2+p  place block + DESK change block + placebo block (each its own amplitude);
  R2t   place block + one continental time feature (window year - cell mean year): a species-wide trend only.
considerations: M11 (placebo), G3/M5 (a species' own trend is the population model's job), M4 (the continental trend
shows only uncentred), M1.
predictions / reading: if R2p >= R2 - 0.02 (corr, both forms), R2's gain is regional trend persistence learned per
species, not DESK's information -- it should NOT be credited to habitat. If R2+p beats R2p by > 0.03 with R2p well
below R2, DESK's within-place change carries species-relevant information beyond a trend. R2t vs R2p separates the
species-wide trend from its regional pattern.
