# E060 Does an eBird auxiliary target reduce DESK's over-fitting -- and does eBird's TEMPORAL change add to it?
# (pre-registered 2026-10-12 ~11:50, before any of these models exist)
hypotheses: [T12 (over-fitting), eBird-places, eBird-trend]     parents: [E057, E058, E054, E055a, E055f/i/k, E039n/E046]
eval_version: pre-v1     cost: 4 x ~65 min gpu + ~40 min cpu
why: the user (2026-10-12): "Are we sure this other angle into the data won't reduce over-fitting?" -- E058 tested
whether the eBird S&T trend agrees with BBS CHANGE (cell level 0.10; species level 0.59), not whether eBird can
REGULARIZE DESK. DESK over-fits places (held-out-place error rises from epoch ~80-110; seed ensembles help, E055i);
regularizers that remove capacity cost time (E054 width, E055b schedule), dropout/weight decay did nothing, and what
helped space and time together kept capacity (the ensemble). An auxiliary target on cells BBS does not survey adds
information without removing capacity. The user also asked that the target carry TEMPORAL change, not only space.
design:
- desk_training's new optional auxiliary head (commit f4a079e): a LINEAR map from z_ema to the target (the age model's
  readout form), its own head, not the shared latent (the August failure, b6e451d), discarded after training.
  Supervised on every covariate-valid footprint cell EXCEPT held-out, buffer and train_frac-dropped cells, never in a
  withheld year; per-column standardization on those rows. Epoch selection, validation and grading: BBS only.
- Targets (research/exp/build_ebird_aux.py), the 91 REFERENCE species with a breeding/resident trend product (DESK
  already trains on these through ESK; no dev or sealed species; never House Finch), years 2012-2021 (inside every
  kept product's window; never extrapolated), footprint 18,584 cells, species without an estimate in a footprint cell
  written as 0 (75% of entries: outside the modelled range):
  - SP (spatial only): log1p(abd), the same in every year; weight 0.1.
  - ST (spatiotemporal): the same 91 level columns + 91 temporal-deviation columns (each cell's log1p of the
    product's annual path abd x (1+ppy/100)^(year-mid), minus its own 2012-21 mean, standardized on its own scale);
    weight 0.2, so the level columns carry exactly SP's weight and the arms differ ONLY by the temporal term.
  The temporal content is small (within-cell sd 0.010 vs between-cell 0.206 in log1p units) and, per E058, agrees
  with BBS change only weakly at the cell level -- the separate columns give it a fair chance rather than letting
  standardization erase it.
- weight 0.1 chosen before any run from the control's loss scale (total ~0.17 at epoch 150; a linear head's
  standardized MSE expected ~0.3-0.5 -> ~20-25% share). The share is logged every 10 epochs; a share outside 5-50% at
  epoch 150 is reported as off-design.
- desk_tempho_1995 (T0 1996), seeds 1 and 2, all else identical to E022 seeds 1/2 (controls; same split).
  Selected and late (epoch 490) caches.
- Evaluation (E057's yardstick, paired vs the same-seed control, same state): fair_rivals --incremental --n-pos 96
  --pos-seeds 1-5 --strong-base: space_level, (a) raw backcast change, (c) beyond the trend placebo, beyond the strong
  base. Plus, post hoc from the logs, the over-fit gap zmse_val_sp / zmse_train (median over epochs 130-170 and
  450-499), and the late-state spatial penalty (space_selected - space_late).
considerations: M28 (one yardstick, paired, matched states), G6/M9 (selected AND late), M10 (two seeds; seed spread on
(a) ~0.024, on (c) ~0.01; one seed is a good draw, E055f2), M11/M20 (adequate placebo), M17-corrected, M23 (held-out
places only; NEVER training-cell change, E055h), M29 (S&T is a smoothed model product: a gain can be smoothness, so
compare beyond-placebo, not raw change, E055k).
caveats fixed now: LEAKAGE -- held-out and buffer cells carry no eBird target, but S&T's own spatial smoothing (wider
than the 54 km buffer) means footprint values near held-out blocks partly encode eBird data FROM them, so any held-out
SPATIAL gain is optimistic; the raw-EBD version (exact control of which checklists enter) is the clean confirmation.
The temporal comparison (withheld 1966-95 vs 2005-25) cannot leak this way: the target covers 2012-2021 only.
predictions (rivals):
- REGULARIZES: the over-fit gap at epochs 450-499 is lower than the control's for both seeds in BOTH arms, and the
  late-state spatial penalty shrinks; space_level at the late state >= control + 0.01.
- HELPS TIME (beyond trend): (c) at the late state >= control + 0.01 with CI > 0 for both seeds.
- TEMPORAL TERM MATTERS: ST - SP on (c) >= +0.01 with CI > 0 (paired via the controls) for both seeds. Prior: weak
  (E058's 0.10 cell agreement), but this is the user's question and the cheap test of it.
- NULL: all within seed noise.
decision rule (both seeds must agree):
- REGULARIZES + HELPS TIME in either arm -> the raw-EBD version (clean, controllable) is the next GPU line, built on
  whichever arm won; if ST > SP, it carries a temporal target too.
- REGULARIZES only -> eBird is a spatial lever (coverage); report what it costs/buys in time; the raw-EBD version is
  worth building for space, not for the backcast.
- NEITHER -> an auxiliary eBird target is not a lever on this evidence; E057 then says whether places matter at all.
- Any spatial gain is reported with the leakage caveat above.

CORRECTION to the seed-1 log note above (2026-10-12 ~18:00, the user): zmse_val_sp, zmse_train and the held-out kernel
loss compare z DIRECTLY with BBS's ESK targets, with no readout. An auxiliary head is MEANT to pull z partly toward
another survey, so these log metrics are biased against every aux arm by construction; "no regularization" was
premature. The test is whether READOUTS fitted on z generalize better -- the pre-registered yardstick (per-place BLR
readouts: space_level, backcast change, beyond-placebo) and the dev-species target (273 species' abundance readouts).
The log numbers stay recorded as what they are: distance from the BBS target geometry. Design note (not changed): the
BBS terms keep their weights; the aux term adds ~30% to the loss and shares the global grad-norm clip, so BBS gets a
smaller share of each step.
Log observation, seed 1 ST arm (2026-10-12 ~21:00; training log only, before any yardstick result): the eBird head's
share of the loss is 51% at epoch 150 and 55% at 490 (standardized MSE 0.89 -> 0.80: the temporal-deviation columns
are hard to fit) -- just OUTSIDE the pre-registered 5-50% band, so the ST arm is reported as OFF-DESIGN as written. The
ST-vs-SP contrast keeps equal per-column weight as designed, but in ST the auxiliary target outweighs the BBS terms.
Selected epoch 157 (val_kernel 0.00787). Interpretation of any ST effect must carry this.

WHY (likely): the S&T product is a smoothed model output whose spatial content largely overlaps what DESK already
learns from its covariates (E039: DESK's spatial edge is a bird-supervised projection of the same covariates), so a
second smooth target adds little new place information, while its share of the loss pulls z off the BBS geometry
the readouts are fitted on. Its temporal part is weak at the cell level (E058: corr 0.10) and here adds nothing.
Not tested here: the raw-EBD version (exact data, our own aggregation) and the user's "eBird z in the BBS basis".
