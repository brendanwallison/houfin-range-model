# E085 The SUM-OF-RUZICKAS readout: do the trained heads' blocks help the age-model readout for sedentary species?
# (pre-registered 2026-10-17, before any run; one smoke of the code on one model, its numbers not read as results)
hypotheses: [representation (multi-source), readout kernel]     parents: [E083, E084b, E084d, E059d]
eval_version: pre-v1     cost: ~30 GPU readout runs (minutes each)
why: the agreed design (2026-10-16) was a sum-of-Ruzickas representation -- per-source blocks with fitted weights in the
downstream readout, so each term is a named similarity. E084 trained the heads but scored every model through z ALONE,
so that readout was never tested (user, 2026-10-17). This tests it on the existing E084b / E084d models.
design: fast_arm.py (the age-model-matched block-prior BLR: raw z, first 24 dims, iid prior per block, amplitudes by
marginal likelihood per species) on each head model's LATE cache, two readouts on the SAME model:
  iso   z (r24) only -- the current downstream contract
  sum   z (r24) + one block per trained metric head, H_h z on the full 64-dim z (--head-ckpt, epoch-490 heads):
        kernel a_B zz' + sum_h a_h (H_h z)(H_h z)'
Models: both heads -- T0 1996 seeds 1-4, T0 1986 seeds 1-2; CBC head seeds 1-2; eBird head seeds 1-2 (T0 1996). Controls'
iso readouts (E022 / E059 seeds, T0 1996 s1-s4, T0 1986 s1-s2) for reference. BLR on GPU (BLR_DEVICE=cuda).
LIMIT stated now: the head blocks are LINEAR functions of z, so they add no information to z; the sum readout can only
RESHAPE the prior (reweight z's geometry by winter / eBird similarity, as E059d's per-block priors did). A gain here
says the reweighting helps; a null does not test independent blocks (that is E086).
scores (e085_summary.py; SEDENTARY primary, residents, migratory): per species spatial level skill, temporal level
skill vs no-change, change skill, attenuation slope (k-like; the peer's request: watch for over-moving); sum - iso
paired per species, median, bootstrap over species.
reading:
- SUM READOUT HELPS if, over the six both-heads models, sedentary change skill (sum - iso) is > 0 in >= 5 AND its mean
  is >= +0.01, AND spatial level skill is not lower by more than 0.005 on average, AND the attenuation slope does not
  fall by more than 0.1 on average (no over-moving).
- HURTS if change skill falls in >= 5 of 6 with mean <= -0.01, or spatial skill falls by > 0.005 on average.
- Otherwise: no detectable effect of the reweighting.
- Reported: block amplitudes (how much weight the readout gives each source).
considerations: sedentary primary (memory), the agreed design tested end to end (memory) -- this tests the READOUT side
with linear blocks only; independent blocks are E086. No House Finch; sealed never read.
