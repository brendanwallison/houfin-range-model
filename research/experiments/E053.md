# E053 Does habitat measured ALONG THE SURVEY ROUTE predict bird change better than the 27 km cell mean? (pre-
# registered 2026-10-11 20:34, before building any route covariate or seeing any result)
hypotheses: [T5, grain (levers item 4), M26]     parents: [E052, E049c, E044d]     eval_version: v1
cost: 32 MB download + ~1-2 h cpu
why: the user approved (2026-10-11) the route-scale test. Every covariate test so far used 27 km cell means.
- Even observed land cover (E052) added only +0.01-0.03, and nothing for forest birds.
- Birds are counted at 50 stops within 400 m of a ~40 km roadside route, so a cell mean may dilute the habitat the
  survey actually samples.
- This asks whether DESK's grid is what limits all the covariate tests.
data:
- Route paths: National Atlas BBS route lines (bbsrtsl020, lower 48, routes as of 1966-1998), from Stanford's copy
  (purl vy474dv5024); sha256 beside the file. The USGS office no longer maintains a current file, and the Patuxent
  server returns HTTP 500.
- Route-level counts: the raw 2026 release (States/*.csv; RPID 101; Weather.csv RunType 1).
- Annual NLCD 1990 and 2019 (already downloaded for E052).
design (research/exp/route_dose.py):
- Routes keyed RTENO = StateNum*1000 + Route, US only. Epochs 1986-95 vs 2014-23 (as E052), with >= 2 valid runs in
  each. Species: the 369 non-sealed community + dev species via src.data.identify.bbs_crosswalk; per route-year
  SpeciesTotal, log1p; ABBA halves by alternating years.
- Route covariates:
  - (R) NLCD class fractions in a 400 m buffer around the route line, 1990 and 2019;
  - (C) the same NLCD classes for the route's 27 km cell (E052's aggregation);
  - (A) ALL DESK covariate change at the route's cell (yearly states, epoch means, standardized).
- Type = 32 PCs of the cell's mean covariate levels.
- Held-out vs training from the desk_tempho_1995_s1 split at the route's cell.
- Guild-pooled ridge, as guild_dose.py --pooled --rival-all. Arms:
  - A;
  - A + R;
  - A + C;
  - A + moved R (8 draws: route-NLCD fields moved among routes).
  Within type and kernel-local (LOO 150 km within each set). Paired bootstrap by 6x6-cell blocks.
- Secondary: routes with the SAME main observer in both epochs (Weather ObsN), to strip observer turnover.
predictions / rule:
- GRAIN MATTERS if, in >= 2 of {grassland, wetland, woodland, forest}, (A+R) - (A+C) >= +0.02 with CI > 0 (either
  mode), and the route gain beats every moved null.
  - In particular: does FOREST respond to forest change along the route, when the cell mean showed nothing (E052)?
- GRAIN DOES NOT MATTER if (A+R) - (A+C) has CI including 0 in every guild.
- Otherwise: report sizes.
caveats:
- Route geometry is as of <= 1998, and some routes were re-routed later.
- 400 m buffers include both sides of the road.
- Guilds are small.
- Route-level change includes observer turnover (~30% of change energy, E021). The same-observer subset addresses
  it.
considerations: M26, M6, M3/M18 (observers), T5.

## E053b Same test, every route out-of-fold (pre-registered 2026-10-11 20:41; disclosed: designed after E053's
## underpowered result)
design: route_dose.py --cv 5.
- Folds are random assignments of 6x6-cell spatial blocks. Each fold's routes are predicted by maps (type basis,
  pooled ridge per guild and arm) fitted on the other folds' routes; the held-out/buffer split is not used.
- All ~2,100 routes are graded once, out-of-fold.
- Kernel-local operates within each fold's evaluation set.
- Bootstrap over 6x6 blocks of all routes.
- Per fold, species need >= 60 training routes; overall, >= 30 evaluated routes.
- Arms, moved nulls and the same-observer subset are unchanged.
- Caveat: no buffer between folds, so regional patterns can leak across fold edges. R and C are treated identically,
  so route - cell remains a fair contrast.
rule: unchanged from E053 (GRAIN MATTERS / DOES NOT MATTER). Also report the grassland route - cell difference,
since it was the suggestive one.

## E053c pre-registration (2026-10-11 20:59): E053b with a stable rival block
Why: in E053b the rival block A was all ~300 normalized covariate-change channels. Pooled across a guild and refitted
per fold, that baseline went anti-predictive for some guilds (wetland A = -0.50), and moved nulls gained up to +0.19.
So "route vs cell" could not be read there.
Change: A becomes the 32 leading principal components of standardized covariate change, fitted over all routes. This is
unsupervised (no bird data), so it leaks nothing about the outcome. Everything else is as E053b: 5-fold spatial-block
CV, the same R (route 400 m buffer NLCD) and C (cell NLCD), 8 moved-route nulls, and both modes.
Rule: unchanged (GRAIN MATTERS / GRAIN DOES NOT MATTER / otherwise report sizes). Added check: a guild counts only if
its base A corr is >= -0.05 (a stable baseline); guilds failing this are reported as uninterpretable.
Predictions:
- If grain limits the covariate tests: route - cell >= +0.02 in grassland and/or woodland and shrubland, beating the
  nulls.
- If not: route ~ cell everywhere the baseline is stable.
- E053b's shrubland hint (+0.027 within type) is the case to watch.
Cost: ~60 min CPU.

- Forest and grassland: route - cell ~ 0.
- Woodland kloc: route - cell +0.045 (CI > 0). But that comes from the CELL arm going negative (-0.041); the route

GRAIN DOES NOT MATTER is not met either (shrubland type and woodland kloc CIs exclude 0). So: report sizes.
WHY:
- The 32-PC rival did NOT cure the wetland or human-modified instability (wetland A -0.42; human-modified CIs past
  -1). So the 300-channel rival was not the cause.
  - Likely cause: a noise-corrected corr can pass +-1 only when its true-signal variance (the ABBA cross-product) is
    small and noisy. That means these guilds' route-level change is barely resolvable from noise, so every arm swings
    wildly.
  - Unverified: the per-guild signal variance is not saved.
- Shrubland's route advantage looks fragile (likely):
  - its size swings with the rival choice (+0.027 in E053b, +0.145 here);
  - it vanishes on the 294 routes with the same main observer in both epochs (-0.005 / -0.034);
  - and its nulls are nearly as large.
  - An observer-turnover artifact fits all three; a real fine-scale shrubland signal is not excluded.
- Forest, the best-powered guild, is ~0 at both grains under both rivals (established for this design): land-cover
  fractions do not carry forest birds' change at the route or the cell.
OVERALL (E053-E053c): no sign that the 27 km grid is what holds the covariate gains to a few hundredths. The one
candidate (shrubland) does not survive the same-observer restriction. Route-scale land-cover inputs are not a lever
on present evidence. Not a FINDING: no skeptic round; it steers only.
