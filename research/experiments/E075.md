# E075 Does early-CBC supervision reach the LAND-COVER response? (pre-registered 2026-10-15, before running)
hypotheses: [CBC (bridge / complement), cover extrapolation]     parents: [E069b, peer E073]     cost: ~1 h cpu
why: the peer's E073: land-cover extrapolation fails for every representation when training lacks places of large cover
change (-0.10 to -0.18 corr beyond the range), 1920-39 cover is novel above all on the Great Plains; the lever is
supervision covering large cover change. E069b's presence term used CBC lists 1940-2024 incl. the withheld years. If
CBC supervises the cover response, its held-out gain should be LARGER where cover changed most.
cover change (research/exp/e075_cover_change_map.py -> cover_change_1920_1966.npz; built before this file): E073's
physical cover (crop / pasture / rangeland / urban fractions, forest, natural non-forest), Euclidean change between the
1918-22 and 1964-68 means, each channel in SD units of 1964-68; terciles over all valid cells (0.279, 1.439). Share of
cells in the top tercile: Great Plains 0.72, west 0.39, east 0.11.

10,599 lists / 1,491 circles in all; Great Plains 1,816 / 285; cover-change top tercile 4,668 / 603; top decile 1,348

design (research/exp/e075_cover_strata.py): per-list gain = arm (backcast - modern) - control (backcast - modern), from
e069b_heldout_lists.py --save-lists (held-out cells, resident species, same readout and offsets as E069b). Strata:
cover-change TOP tercile vs rest; Great Plains vs rest. Era 1953-1995 pooled (primary), 1953-65 and 1966-95 reported.
Difference top - rest, 95% bootstrap over circles within each stratum. Arms: w0.01 seeds 1 and 2 (late primary;
selected reported), w0.04 seed 1 late.
reading: CBC SUPERVISION REACHES THE COVER RESPONSE (detectably) if, pooled 1953-1995, LATE, the top-tercile gain
exceeds the rest with the interval excluding 0 for BOTH w0.01 seeds. Interval covering 0 -> not detectable (POWER IS
LOW: ~20-40 held-out circles in the top tercile); negative with the interval below 0 -> the gain is concentrated where
cover changed LEAST. Great Plains reported if >= 3 circles per stratum; it is likely too thin.
confound (stated before data): the top tercile is mostly Great Plains and west, the rest mostly east; a difference can
be regional (control errors differ by region) rather than cover-specific. Not separable at this n.
considerations: M17-corrected (a gain is predictability, not cause), M28, G11 (winter lists), no House Finch, sealed
never read.

## E075b AMENDMENT (2026-10-15, before any E075 result): widen the test set to held-out + BUFFER cells
The peer suggested widening the test set beyond DESK's held-out cells. DESK's buffer cells (the ring excluded from
training around each held-out block) were never in BBS training nor in the presence term (the trainer drops them), so
their lists are equally unseen. 1953-1995 lists in cached cells: held-out 2,516 / 166 circles (top cover tercile 640 /
37); held-out + buffer 5,086 / 331 (top tercile 1,526 / 86). E075b repeats E075 exactly with --cells holdout_buffer
(species offsets fitted on the remaining training cells only). Same reading rule, applied to E075b separately; buffer
cells sit next to training cells, so their gains may be larger for that reason alone -- the top-vs-rest contrast, not
the level, is the test.

READING (pre-registered, E075 and E075b alike): NOT DETECTABLE -- the late-state top-tercile minus rest intervals
cover 0 for both seeds; the gain is about as large where cover changed most as elsewhere (+0.16-0.20 vs +0.19 with the
buffer cells). At the selected states it is, if anything, SMALLER there. Great Plains (secondary): positive at the late
state in both seeds (+0.06-0.07, intervals touching 0; +0.09 with the interval just above 0 at w0.04), negative or null
at the selected states -- not consistent across states.
WHY (likely). The presence term's held-out gain is BROAD: it mostly removes DESK's over-movement back in time everywhere
(late controls over-move most, E069b), rather than teaching a cover-specific response where cover changed most. The
Great Plains lean at the late state is suggestive, not established (28 circles; state-dependent sign).
NEXT (candidate, not pre-registered): a decisive test needs held-out places INSIDE the high-change zones in numbers --
withhold a random half of CBC CELLS (stratified by zone and cover tercile) from the presence term in a retrain and score
those cells' lists (~140 Great Plains circles instead of 28).
