# E037 Repair the covariate GP baseline (defect A13) until it is an acceptable baseline
hypotheses: [A13]     parents: [E006]     eval_version: pre-v1     cost: rung 0-1 (harness), then a suite re-run (~2 h gpu each)
pre-registered: 2026-10-10 ~20:14 (the user: "Wouldn't the solution be to iteratively revise the covariate GP approach
until it is an acceptable baseline?"), before any variant was run.

why it matters: a GP straight from the covariates to each species, with no community embedding, is the most direct
test of whether DESK adds anything; with it broken, that question was unanswered. The spacetime GPs share the bound
problems (E006: product time lengthscale at its upper bound; spacetime_sum degenerate) and are repaired next.
diagnosis (code map, 2026-10-10): (1) lengthscale bounds come only from the ~3 contiguous patches the shape is fitted
on; a channel barely varying there is capped near e^-7 (my own cd4fb91 fix for an earlier crash produced exactly this),
while on prediction rows such channels (land use c4per, flood) span ~20 sd and dominate distances; (2) 302 collinear
channels, no reduction; (3) a nearly flat kernel with an inflated amplitude (global-mean centring, a 1e3 start
multiplier, an absolute log-s2 cap) -- unstable, absurd means; (4) a line search that aborts.
design: research/exp/covgp_harness.py reproduces the suite's covariate arm with its own routines (fit_shared_shape,
blocked_scales, predict_local) on the gp_species_base cache and changes one piece at a time: features (302 channels |
32 whitened PCs), bounds (shape rows | all training rows in units of each feature's spread, [0.05, 20] sd), shape
sample (a few contiguous blocks | many small random blocks), amplitude (uncapped | s2 <= 10 var_y, no 1e3 start).
Variants: v0 suite (reproduce the failure), v1 bounds only, v2 PCA + bounds, v3 PCA + bounds + stratified sample,
v4 = v3 + amplitude cap.
ACCEPTANCE CRITERIA (fixed now): A1 fit health -- converged, or stopped by the iteration cap with < 10% of
lengthscales at a bound; A2 sanity -- < 0.1% of held-out predicted log1p means outside [-1, max observed + 1] and the
median ratio of max predictive variance to the species' variance < 3; A3 leave-one-out level skill on training rows,
median over species > 0; A4 held-out level skill, median > 0, and not worse than a linear (BLR) covariate model on the
same features (median GP - linear >= -0.01).
decision: the first variant meeting A1-A4 is ported into validate_gp_species (as options, then defaults), unit tests
added (constant / heavy-tailed channels, prediction range), and E006 re-run on both models; if none passes, diagnose the
failing criterion and iterate (kernel choice, centring per block, multi-start shape fit) before anything else.

## Diagnosis after round 1 (why the GP fails on new places)
established: the amplitude is wildly inflated (s2 26x the species' variance in v2) with most lengthscales near their
upper bound; capping s2 helps (v4) but not enough. likely (two artifacts of fitting on CONTIGUOUS blocks, centred on the
continental mean): (a) each block sits at its own regional level; in a block-diagonal likelihood the only way to
explain a block-wide offset is a near-constant kernel mode, which a long lengthscale and a huge s2 supply -- the GP
becomes a local polynomial with a free intercept per block, which extrapolates wildly from a local conditioning set;
(b) a block holds every year of each of its cells, so a place's lasting departure from what its covariates predict
looks like smooth covariate signal (high s2, low noise). A smoke run with a same-cell kernel term on contiguous blocks
(600 rows, 4 iterations, not a test) drove the cell weight to its floor while s2 rose to 370x var: (a) dominates.
smoke runs disclosed: before writing this, two 600-row/4-iteration smoke runs were made to check the code; the second,
v6's configuration, gave held-out +0.274 vs linear +0.292 (s2/var 0.55, max pred var 1.26x). They are code checks, not
results, but they were seen before this pre-registration.

## Round 2 (pre-registered 2026-10-10 20:34, commit c3d6f03, before any full run)
harness additions: --sample random (the shape fitted on ONE block of rows drawn from the whole continent: the global
mean is then the right centring, and a cell rarely repeats, so a place's quirk falls to the noise), --scale-sample
random (per-species scales from all training rows cut into random 1000-row blocks instead of contiguous ones),
--resid-linear (the GP models what the 64-PC linear BLR leaves: mean function = the linear model), --cell/--linear
kernel terms (kept for later), evaluation rows from their own seed (identical across variants).
variants: v2b = v2 rerun as the matched control; v5 = pca + data bounds + random shape sample + random scale blocks;
v6 = v5 + linear mean; v7 = v6 on the 302 raw channels (is PCA needed?).
predictions: if artifact (a) is the cause, v5 and v6 have s2/var < 3, < 10% of lengthscales at a bound, max pred var
< 3x, and held-out skill at least 0.1 above v2b; if v5 ~ v2b, (a) is wrong. v6 - v5 >= 0.02 would mean the local GP
misses a global trend the linear mean supplies; v6 ~ linear would mean little nonlinear covariate structure is
recoverable at this level. v7 ~ v6 means PCA is optional.
decision: unchanged (first variant meeting A1-A4 is ported). If v6 passes only by riding the linear mean (v6 - linear
within +/-0.01), it still passes A4 as written -- the baseline is then "linear covariate model + GP correction", which is
an honest covariate baseline -- but that will be stated.
considerations: G7 (a repair, judged by fixed criteria, not by whether it makes DESK look good or bad), M21 (A3 is a
low bar), M9 (level skill here; change skill is judged later in the suite), P2 (pre-registered before results).

## Round 3 (pre-registered 2026-10-10 20:47, commit f46a041, before any full run)
fix: put the cell effect in the kernel, k = RBF + rho [same cell], fitted jointly with the lengthscales, so that at
prediction a training cell's repeated years are discounted as one place's quirk and a held-out cell's own effect is
unknown (mean 0). rho needs same-cell pairs in the fit, which random rows lack, so the samplers become RANDOM CELLS:
the shape on ~3000 rows from random cells, --years-per-cell of each (continental, so the global mean still centres
right), the scales on random groups of whole cells (~1000 rows each).
smoke disclosed: one 600-row, 2-iteration code check of v8's configuration gave rho 0.21, held-out +0.348 vs linear
+0.292 on 300 evaluation rows (a different, smaller evaluation sample). Seen before this pre-registration.
variants: v8 = pca + data bounds + random cells (4 years each) for shape and scales + linear mean + cell term; v9 = v8
with a constant mean (is the linear mean still needed once the cell effect is modelled?); v10 = v8 with 30 years per
cell (whole cells: more information on rho, fewer cells for the lengthscales).
predictions: if prediction-time leakage of cell quirks is why v6's GP subtracts, v8 has rho clearly above 0 (>= 0.1),
mean spread close to the linear model's, and GP - linear >= 0 (passing A4); if v8 ~ v6, the leakage story is wrong and
the remaining gap is a kernel-shape problem (next: Matern-3/2, multi-start). v9 within 0.01 of v8 means the linear mean
is optional once cells are modelled. v10 vs v8 tells whether the result depends on how rho is identified.
decision: unchanged. considerations: as round 2, plus G7: a baseline that merely ties the linear model is still worth
having only if it is the honest nonlinear rival; if every GP ties linear, the report will say the covariate signal at
this scale is close to linear and keep covariate_linear as the matched baseline.

covariates' nonlinear structure recoverable at this scale is real but modest.

bounds, the cell kernel against the dense GP, a planted quirk-copying test, the samplers.
