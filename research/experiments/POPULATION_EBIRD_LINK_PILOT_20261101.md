# Fixed-population breeding eBird comparison — registration, 2026-11-01

Purpose: connect the completed focal eBird data to the existing annual population readout while holding demographic parameters fixed. This is an observation/readout comparison, not a joint demographic refit or an independent biological validation of the BBS census convention. Registered before inspecting these population-linked eBird scores.

Census adapter parity has passed exactly against all 192,123 pre-observer BBS rows at the absolute-Allee reference, including seeded initial-year pseudozeros. Readout is previous-year total plus current-year young times a source-visibility weight, in the existing route-count gauge. Source-specific eBird nuisance coefficients never inherit BBS observer offsets.

Fixed references: step33_nestcbc_s41 (relative Allee), step33_nestcbc_abs_s41, and step34_abs_natdep_s41. Each is an accepted frozen point with its own source and checkpoint. Compare young-visibility weights 0, its fitted BBS weight, and 1 as stated sensitivity cases, not estimated demographic changes. The BBS weight is a reference, not an assertion that eBird has the same visibility. All arms use the same June-only Canadian checklist cohort, on modeled land cells and in modeled years; report exclusions. This limits census-window mismatch. Reuse outcome-independent cell/year/week thinning and the pinned 216-km spatial/2021–25 temporal holdouts. The earlier full-window source pilot is not a matched comparator.

Observation pilot: standard two-part/hurdle framework (Johnston et al. 2021 and Cornell eBird abundance guide), implemented using statsmodels Binomial GLM and zero-truncated NB2. For the population-linked encounter component use complementary log-log probability p=1-exp(-q(E)*A), with log(A) an offset. This is the standard Poisson-intensity-to-encounter relation discussed by Royle & Nichols (2003), https://pubs.usgs.gov/publication/5224229, and Aarts et al. (2012), https://doi.org/10.1111/j.2041-210X.2011.00141.x. We do not claim to fit the full repeated-survey Royle–Nichols abundance model. Positive-count component uses log mean = log(A)+observation-effort predictors, conditioned on positivity. The two parts have separate nuisance coefficients; this is an empirical hurdle observation model, not a single literal thinning process or absolute detection estimate.

Effort predictors are log duration and its square, log(1+distance), observer count, time-of-day sine/cosine and protocol. No free spatial field or year trend is allowed in population-linked observation nuisance terms. Comparator arms are effort-only and the same low-dimensional geographic/year baseline, fitted with the same cloglog/hurdle model to the exact same rows. The relative count scale is absorbed by source intercepts; it must not be interpreted as absolute population size. Identifiability of the annual demographic parameters is not supplied by this calibration alone.

Report convergence, warnings, held-out joint hurdle scores, encounter calibration and Brier scores, and paired log-score contrasts to the matched geographic baseline. Exploratory 90% block-bootstrap intervals resample 216-km blocks, conditional on the fitted MAP points and observation coefficients; report block counts and do not call these demographic uncertainty intervals. Holdouts have already been examined in earlier exploratory work, so this is not an untouched confirmatory test.

A poor fixed-population fit can be biologically informative. Do not add flexible observation fields simply to hide ecological disagreement. Conversely, a score gain does not establish the census interpretation or justify a mechanism. Before a full joint refit, validate the source/census likelihood mapping and its parameter response using known synthetic inputs; then evaluate whether new observations actually reduce the full pathology inventory rather than moving distortions elsewhere.

Numerical amendment after the initial attempt: default IRLS initialization failed for the population-offset encounter fits, so their apparent score contrasts are invalid. Preserve that attempt separately. Initialize only the encounter intercept to match the training marginal encounter rate under its fixed offset, and initialize the truncated-count intercept using its alpha=1 conditional-mean identity. Then optimize the identical likelihood with the standard library solver. No held-out values, demographic changes, new priors or relaxed convergence criteria enter initialization. Converged encounter and count components are both required before any predictive contrasts are reported. Compare an independent optimizer on a representative arm as a numerical cross-check.

## Follow-up: full-count NB2 observation control

The initialized hurdle run fixes encounter convergence but exposes a boundary in the separate truncated-positive-count component: large alpha (~10^6) and shrinking mean scale, with Hessian warnings and several optimizer failures. Do not use that component as a demographic likelihood merely because some optimizers report convergence.

Register a simpler full-count negative-binomial observation control before fitting it. This follows the same shared-state/distinct-observation architecture and the existing BBS NB2 count family: mean = population readout × exp(source-effort predictor), one source concentration. Numeric zeros and positive counts enter the same count likelihood. An X record contributes P(Y>0) under that same distribution, rather than being assigned a count or discarded. Fit with NumPyro's existing negative-binomial distribution and standard SciPy L-BFGS, using automatic derivatives. This is a different registered observation model, not a silent solver fix for the hurdle model.

Use exactly the same June cohort, references, visibility sensitivities and holdouts. Standardize predictor columns using training data only and initialize the intercept to the training numeric-count mean under the fixed offset. Report nuisance concentration, gradients/convergence, paired scores and calibration. No new ecological field, source-year correction, demographic parameter or informative prior is added. These are still fixed-point observation comparisons. A failure of frozen demographic predictions is not itself a reason to reject a correctly specified observation likelihood, but observation scale/dispersion degeneracy must be resolved before joint inference.
