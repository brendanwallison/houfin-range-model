(96 species, 16,000 landmarks); truncation leaves ~14% normalized RMSE on the centred kernel (centred effective rank
~53), so structure exists beyond 64, but going there needs a new ESK fit and DESK retraining. Within 64: DESK's change

amplitude would let each species' readout use the tail when its data support it and shrink it when they don't. If that
reconciles the two regimes, a higher rank would be worth having only under such a prior.

==== E086y-b (pre-registered 2026-10-23, before E086y reports) THE COUNT TRANSFORM INSIDE THE KERNEL ====
why (user): a Ruzicka kernel on RAW counts lets common species dominate and registers abundance shifts (a uniform
doubling halves similarity); log1p mostly encodes composition. Ruzicka stays positive semi-definite for any
non-negative elementwise transform, so the transform is a free modelling choice. sqrt (Hellinger-style) is the
standard middle ground.
design: E086y unchanged except --transform {sqrt, raw} for the reference counts inside both kernels (targets stay
log1p, the age model's scale). log1p is E086y itself.
reading: for each candidate kernel, transform T is BETTER than log1p if capture (change readout, r24, dev sedentary
common) rises by >= 0.25 and noise-free change corr is not lower by > 0.02. Reported for every kernel x transform.
caveats (likely): raw counts are heavy-tailed (flocking / colonial species), so a raw kernel may collapse onto a few
noisy species and raise the noise floor; Mourning Dove, the largest riser, is a dev species and not in any kernel.
