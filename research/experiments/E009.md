# E009 Planted calibration with power: the readout's ceiling by prevalence, and is the attenuation estimator unbiased?
hypotheses: [E1, B7]     parents: [E007]     eval_version: pre-v1     cost: ~20 min cpu
pre-registered: 2026-10-09, after the E007 pilot (12 species/generator, numbers below), before this run

question: Under the real sampling design (tempho1995 keys, route-mean NB counts), what change attenuation, captured
share and level skill can the age-model-matched readout show for a species whose log-mean is EXACTLY linear in DESK
raw z (generator z), by prevalence tier; and does the suite's noise-corrected attenuation estimate match the slope
against the noise-free truth where species are resolvable?

design: planted.py --n-per 60 --seed 1 (360 species: z, spacetime, mix_0/0.1/0.3/0.6), then fast_arm A0 (iso) and A3
(split) with --dump-change, graded by planted_report.py (truth = epoch-mean lambda through the suite's log1p-of-mean
estimand). Tiers: prevalence [0,0.02), [0.02,0.1), [0.1,0.3), [0.3,1].

pilot (E007 rerun with --dump-change, n=1-7 per cell): z generator TRUE attenuation (time set) 0.22 / 0.34 / 0.59 /
0.75 by tier; true change share of observed variance 0.001 / 0.04 / 0.07 / 0.29; est/true real-change variance ~1
where resolvable, unbounded where not.

predictions:
- z generator TRUE attenuation (time set, all species) rises with prevalence: tier medians in [0.1,0.45], [0.2,0.55],
  [0.4,0.75], [0.55,0.95].
- Estimator: in tiers with >= 10 resolvable z species, median(estimated / true attenuation) in [0.7, 1.3].
- true change share < 0.05 below 10% prevalence for every generator.
- A3 vs A0 on the z generator: |median true attenuation difference| < 0.1 (iso is the exact model there; split
  should not cost much). On mix_0.6, A3 >= A0.
- spacetime / mix generators under A0: true attenuation |median| < 0.1 (z cannot carry an unrelated field).

decision rule: real-species A0 attenuation (E005: 0.002-0.04 median) is compared with the z ceiling IN THE SAME
PREVALENCE TIER. Real >= 0.5 x ceiling in a tier -> the instrument, not the model, limits that tier. Real < 0.2 x
ceiling -> the loss is real (upstream or readout form; E011 says which). An estimator ratio outside [0.7, 1.3] ->
the attenuation statistic is biased and every E005 attenuation must be re-read before use.
