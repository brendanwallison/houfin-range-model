# E061 A CBC auxiliary head, alone and with eBird: three signals against DESK's over-fitting
# (pre-registered 2026-10-12 ~12:25, before any of these models exist)
hypotheses: [T12 (over-fitting), eBird-places, CBC (new)]     parents: [E060, E057, E058, E055a, E055f/i/k]
eval_version: pre-v1     cost: 4 x ~65 min gpu + ~40 min cpu
why: the user (2026-10-12) asked for a CBC trend head beside the eBird one, "so we have three signals, each carrying
distinct information" (BBS breeding counts on routes; eBird S&T breeding/resident abundance and trend on a 27 km
grid; CBC winter counts in circles, as regional annual indices). M29 rules CBC out as a PRE-1966 ground truth; it does
not rule out its post-1966 indices as a regularizing target on its own head.
data: Audubon CBC relative-abundance indices version 2023.0 (user-supplied, data/cbd_trends; unpacked to
/mnt/e/Datasets/houfin/external/cbc_trends_2023 with the zip's sha256): per species, an effort-corrected annual index
for each MODELING STRATUM (state/province x BCR), winters ending 1967-2024. Built by research/exp/build_cbc_aux.py:
- strata placed on the grid by each cell's NEAREST BBS route start (Routes.csv gives state and BCR), within 150 km;
  152 strata over 17,370 cells; edges blurred, no BCR polygons on hand;
- species: REFERENCE species only in practice -- the builder also admits species graded nowhere (not dev, not
  sealed), but none survived the filters (survey suitability medium/high, >= 5 strata, single-species names): 32
  reference species. Dev and sealed species never enter; House Finch never;
- target (24 years x 2S columns): level = log1p(index) averaged over the kept winters (static), and temporal
  deviation = each winter's log1p(index) minus its stratum mean -- E060's ST split. Here the temporal part is real:
  within-stratum sd 0.264 vs 1.660 between strata (eBird ST: 0.010 vs 0.206);
- WINTERS ENDING 2001-2024 ONLY (T0 1996 + 5): the CBC model smooths across years, so indices just after T0 borrow
  from withheld winters; the trainer also drops withheld years. The file is named for T0 1996.
design: desk_tempho_1995 (T0 1996), seeds 1 and 2, all else as E022 (controls; same split); desk.aux list:
- CBC: the CBC head alone, weight 0.2 (2S columns, so each column carries E060-SP's per-column weight 0.1);
- ALL3: eBird ST head (weight 0.2, as E060) + CBC head (weight 0.2) -- the "three signals" model.
Same yardstick as E057/E060 (held-out cells only, paired vs the same-seed control, selected and late states, adequate
placebo, strong base), plus the over-fit gap (zmse_val_sp / zmse_train, epochs 130-170 and 450-499), the late-state
spatial penalty, and each head's loss share (logged every 10 epochs; outside 5-60% combined at epoch 150 =
off-design). E060's SP/ST arms and this experiment's CBC/ALL3 arms together give: control, eBird-SP, eBird-ST, CBC,
eBird-ST+CBC on two seeds.
considerations: M28, G6/M9, M10, M11/M20, M17-corrected, M23 (never training-cell change, E055h), M29.
caveats fixed now: LEAKAGE -- CBC circles physically inside held-out blocks contribute to their stratum's index,
which supervises the TRAINING cells of that stratum; and the stratum's 2001-24 winter trajectory relates to the
modern end (2005-25) of the held-out cells' backcast change. Any held-out gain, spatial or beyond-trend, is
therefore somewhat optimistic; the BBS trend placebo already carries the neighbours' modern trend, so the beyond-
placebo measure is the least affected. The withheld early end (1966-86) cannot be reached. Winter and breeding
communities differ: a CBC gain is a regularization effect, not evidence about breeding habitat.
predictions:
- REGULARIZES: over-fit gap (450-499) below the control for both seeds; late-state space_level >= control + 0.01.
- HELPS TIME (beyond trend): (c) late >= control + 0.01 with CI > 0 for both seeds. The CBC head is the first aux
  target with substantial temporal variation, so if any of these arms helps time, CBC/ALL3 are the likeliest.
- ALL3 >= max(E060-ST, CBC) on (c) and space_level (signals add rather than conflict).
- NULL: all within seed noise.
decision rule (both seeds must agree): as E060 -- REGULARIZES + HELPS TIME in any arm -> its raw-data version
(EBD; CBC circle-level data if obtainable) is the next line; REGULARIZES only -> a spatial lever, reported with the
leakage caveat; NEITHER -> auxiliary targets are not a lever on this evidence. Read jointly with E057 (do places
matter at all) and E060.
